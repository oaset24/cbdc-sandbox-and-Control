# CBDC Sandbox & Control Infrastructure

## Ziel
Entwicklung einer staatlich orientierten CBDC-Simulationsplattform zur Demonstration von:

- zentraler Kontrolle (Zentralbank)
- Distribution (Banken)
- Nutzerinteraktion (Wallets)
- Compliance (AML/KYC)
- programmierbarem Geld

## Nicht-Ziele
- Keine echte Kryptowährung
- Keine Dezentralisierung
- Kein anonymes System

## Zielkunden
- Banken
- FinTechs
- Öffentliche Institutionen
- Forschungsprojekte

## Kernprinzipien
- Full Control by Authority
- Auditability
- Compliance First
- Security by Design
